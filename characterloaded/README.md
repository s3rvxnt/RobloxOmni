# CharacterLoaded Stage (Ring 3)

Scripts placed in this folder wait until your **local character spawns** (`LocalPlayer.CharacterAdded`) and the root part is ready before executing.

### Best Used For:
* Fly scripts, speed hacks, and custom character controllers
* Tool auto-equippers & weapon mods
* Hitbox expanders & character-attached visual rings
* Physics hooks requiring an active Humanoid / HumanoidRootPart
